01-Emmet

Plugin para codificación más rápida en HTML y CSS.

01-Child: >
Crea elementos hijos (anidación).

Ejemplo:

ul>li>a ↔️

Resultado:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: +
Crea elementos hermanos (anidación).

Ejemplo:

section+header+nav ↔️

Resultado:

<section></section>> <header></header> <nav></nav>

03-Multiplication: *
Repite elementos multiples veces.

Ejemplo:

ul>li*3 ↔️

Resultado:

<ul> <li></li> <li></li> <li></li> </ul>>

04-Class: .
Crea un atributo de clase.

Ejemplo:

menu.mainmenu ↔️

.container

Resultado:

<menu class="main"></menu> <div class="container"></div>

05-Classes: ...
Crea múltiples atributos de clase.

Ejemplo:

menu.mainmenu.uppercase.blue ↔️

.container

Resultado:

<menu class="mainmenu uppercase blue"></menu>

06-Id: #
Crea un atributo de ID.

Ejemplo:

nav#navigation123 ↔️

Resultado:

<nav id="navigation123"></nav>

07-Text: {}
Inserta contenido de texto.

Ejemplo:

div{lorem ipsum dolor} ↔️

a{Clic aquí} ↔️

Resultado:

<div>lorem ipsum dolor</div> <a href="">Clic aquí</a>

08-Custom Attribute: []
Crea atributos personalizados.

Ejemplo:

a[href=www.google.com] ↔️

Resultado:

<a href="www.google.com"></a>

09-Item Numbering: $
Añade números consecutivos.

Ejemplo:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>>

10-Reverse Numbering: @-
Invierte el orden de numeración.

Ejemplo:

ul>li.num$@-*3 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>>

11-Base Numbering: @n
Define un número base para secuencias.

Ejemplo:

ul>li.num$@3*4 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>>

12-Climb Up: ^
Sube un nivel.

Ejemplo:

section>article>div^p ↔️

Resultado:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping: ()
Agrupa elementos juntos.

Ejemplo:

(header>nav)(section>article) ↔️

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem: lorem
Genera texto de relleno.

Ejemplo:

lorem ↔️

lorem20 ↔️

lorem*5 ↔️

Resultado:

15-HTML Documents: html
Crea varios tipos de documentos HTML.

Ejemplo:

html:xt ↔️ Documento xhtml 1.0 Transitional

html:4s ↔️ Documento html 4.01 Strict

html:4t ↔️ Documento html 4.01 Transitional

html:5 ↔️ Documento html 5

Resultado:

16-Meta Tags: meta
Genera etiquetas meta.

Ejemplo:

meta:vp ↔️

Resultado:

17-Challenge
Genera desafíos de Emmet para práctica.

Ejemplo:

header#header>nav.navbar.navbar-inverse>.container>(div.navbar-header>button[type="button"].navbar-toggle>(span.sr-only{Toggle navigation}+span.icon-bar*3)+a.navbar-brand[href="index.php"]>img[src="imgs/logo.png" alt=""])+div.collapse>ul.nav.navbar-nav>(li>a.link[href="index.html"]{Inicio})+li.active.link>a[href="login.html"]{Ingresar}+(li>a.link[href="registro.html"]{Registrarse})+li>a.link[href="contacto.html"]{Contacto}

Resultado:

<header id="header"> <nav class="navbar navbar-inverse"> <div class="container"> <div class="navbar-header"> <button type="button" class="navbar-toggle"> <span class="sr-only">Toggle navigation</span> <span class="icon-bar"></span> <span class="icon-bar"></span> <span class="icon-bar"></span> <a href="index.php" class="navbar-brand"> <img src="imgs/logo.png" alt=""></a> </button></div> <div class="collapse"> <ul class="nav navbar-nav"> <li><a href="index.html" class="link">Inicio</a></li> <li class="active link"> <a href="login.html">Ingresar</a> <li> <a href="registro.html" class="link">Registrarse</a></li> <li> <a href="contacto.html" class="link">Contacto</a></li> </li> </ul> </div> </div> </nav> </header>
